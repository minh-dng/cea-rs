# cea-rs

Experimental Rust thermochemistry and equilibrium with Python bindings.
Distribution: `cea-keplr-rs`. Python import: `cea_rs`.

This is an independent Keplr project derived from attributed NASA data and
existing Rust solver work. It does not replace the `cea` distribution and
is not endorsed by NASA. Full CEA parity is not established.

Implementation and comparison evidence will be recorded on the implementation
branch before the first release. Native NASA CEA remains the production default.
